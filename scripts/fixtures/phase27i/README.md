# Phase 27I short-circuit logical-operator proof sources

These bounded sources exercise `&&` and `||` as canonical value-producing
operators with genuine expression-level short-circuit branches. They cover
truth tables, comparison precedence, nested and mixed expressions, assignment,
conditions, invalid syntax, single-character rejection, deterministic output,
and the Developer Studio source-edit/build/run path.

The language remains integer-only, function-scoped, AMD64-only, and has no
loops, bitwise operators, or user-defined functions.
