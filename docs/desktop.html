guideXOS Desktop Guide

The guideXOS desktop is the graphical shell for guideXOS Server. It hosts windows, the taskbar, system tray, and built-in applications.

The Taskbar

The taskbar at the bottom of the screen shows running applications and the system tray.

Click an application button to bring it to the foreground.

Windows

Each application runs in its own window. Windows can be moved, resized, minimized, and closed using the title-bar controls.

Built-in Applications

  • Navigator – document viewer and browser shell
  • Notepad – plain text editor
  • Calculator – basic arithmetic
  • File Explorer – browse the filesystem
  • Disk Manager – view storage devices
  • More applications coming in future releases

Launching Apps

Applications can be launched from the desktop or taskbar. The guideXOS app model uses a JSON manifest and a native binary:

{
  "name": "MyApp",
  "entry": "myapp.elf",
  "version": "1.0",
  "icon": "myapp.png"
}

App Manifest Fields

  • name – display name shown in the taskbar and desktop
  • entry – path to the ELF or GXAPP binary
  • version – semantic version string
  • icon – optional path to a PNG icon
