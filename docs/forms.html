Navigator Forms Test

This page exercises Forms-lite POST v0.1 controls: text input, checkbox, radio, textarea, and select. Form 1 uses GET so the query string can be inspected in the address bar. Form 2 posts URL-encoded fields to the deterministic hosted smoke server.

Form 1 - GET (all controls)

Form 2 - Hosted POST (all controls)

Expected results:

  • GET submit opens forms-result.html with q=..., subscribe=yes, color=blue, note=..., size=medium in the URL.
  • Hosted POST sends an application/x-www-form-urlencoded body when the deterministic local smoke server is running.
  • POST to file:// remains unsupported and is reported honestly.
  • Tab and Shift+Tab move focus between controls without touching the address bar.
  • Space toggles checkbox, selects radio, cycles the select dropdown.
  • Textarea supports typing, backspace, and newline.
