## ?? Behind The Scenes

The script automatically:
- ? Finds its own location (`scripts\`)
- ? Goes up to project root
- ? Locates the kernel (`kernel\build\x86\bin\kernel.elf`)
- ? Launches QEMU
- ? Returns to your original directory

---

## ?? Alternative: VNC Remote Viewing

If you want VNC instead:

```bash
run-qemu-x86-vnc.bat
```

Then connect from another computer: `vncviewer your-ip:5900`

## ?? If Kernel Not Built Yet

If you get "Kernel not found" error:

```bash

cd ..\scripts
run-qemu-x86.bat
```
