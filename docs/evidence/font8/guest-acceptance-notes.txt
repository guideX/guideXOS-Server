Environment limitations observed
- QMP system_reset caused this WHPX QEMU process to exit with “Unexpected VP exit code 4”; persistence was therefore checked by quitting the private process and starting a fresh one from the same ESP.
- QEMU's directory-backed FAT VVFAT drive emitted “Error handling renames (-2)” and exited when a later preference transaction replaced a slot already present on the host directory. Successful guest saves used previously unused slots. Hosted FONT6/FONT8 suites cover repeated transactions and rollback; this QEMU VVFAT behavior is not treated as a kernel font failure.
- Fresh boots repeatedly showed a concentric cursor-area rectangle artifact at screen center. It did not prevent desktop or Settings interaction and also appeared with bitmap rendering.
