# ?? BOOT YOUR OS - Even Simpler Now!

## ? Scripts Work From Anywhere!

You can now run the scripts from **any directory**!

---

## ? THE SIMPLEST WAY

**If you're in the `scripts` directory (like you are now):**

```bash
run-qemu-x86.bat
```

**That's it!** Just type that and press Enter! ??

---

## Alternative: One-Liner Build & Run

**From any directory:**

```bash
cd kernel && build-x86.bat && cd .. && scripts\run-qemu-x86.bat
```

---

## ?? What Happens

1. **Build** - Compiles kernel (if using one-liner)
2. **Launch** - Opens QEMU automatically
3. **Boot** - Shows splash screen
4. **Desktop** - Displays teal gradient + taskbar
