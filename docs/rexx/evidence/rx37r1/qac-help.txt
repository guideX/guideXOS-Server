guideXOS QAC command-line client
Usage:
  qac <status|list|queue|help>
  qac request --project <name> --mode <development|acceptance>
  qac run --project <name> --mode <development|acceptance> -- <qemu-system-*.exe> [arguments...]
  qac inspect <reservation-id> | cancel <reservation-id> | release <reservation-id>
request holds an admitted reservation until release or Ctrl+C; it never detaches.
run starts QEMU itself as the direct child, preserves arguments and exit code, and rejects wrapper executables.
Exit codes: 0 success, 2 coordinator unavailable, 3 coordinator/protocol error, 64 usage error, 130 interrupted while waiting.
